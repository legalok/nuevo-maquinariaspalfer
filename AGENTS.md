# Instrucciones para el Agente

- Cuando el usuario mencione que tiene una duda o una pregunta (o use palabras como "pregunta", "duda", "¿es posible...?"), **NO** realices cambios en el código inmediatamente.
- Primero, responde a la pregunta de forma detallada.
- Después, solicita confirmación explícita (feedback) preguntando si el usuario desea que implementes la solución o si prefiere dejar el código como está.
- Prioriza la asesoría informativa antes de la ejecución técnica en estos casos.
